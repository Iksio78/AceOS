**AceOS**

AceOS is a hobby operating system written in Rust for x86-64 architecture.

## Features
 - [x] Serial Port output
 - [x] Framebuffer output
 - [x] GDT and IDT
 - [x] Physical memory management
 - [x] Virtual memory management
 - [x] Kernel Heap
 - [ ] PS/2 keyboard support
 - [ ] Scheduler
